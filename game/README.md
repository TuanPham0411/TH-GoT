# Game Of Thiên runtime

Thư mục này chứa Flask, giao diện và JSON cấu hình ban đầu. Runtime hiện đọc ảnh và nội dung đang biên tập trực tiếp từ Google Drive; không cài ảnh hoặc ghi thumbnail xuống đĩa.

Xem [README triển khai](../README.md) và [hướng dẫn Drive](../docs/ASSETS.md). Công cụ audit/pack trong lịch sử source phục vụ đối chiếu dữ liệu ban đầu, không phải startup của bản triển khai hiện tại. `assets.py` cũ không được đưa vào image.
